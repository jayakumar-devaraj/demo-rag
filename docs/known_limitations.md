# Known Limitations

- **Task 2 cut (agreed 21:57):** TXT files go through the DOCX text path, with no separate worker. PDF tables are detected with PyMuPDF `find_tables()` only; there's no extra layout-coordinate handling. Reason: 5-minute drift overrun at the Task 1 checkpoint.
- **No model credentials (option c, agreed 21:57):** no embedding or LLM provider key is available. Tests use a labeled test-double embedder, and every real LLM path (synthesis, sufficiency check, Ragas scoring) is UNEXECUTED.
- **UNEXECUTED — real LLM and embedding calls (Task 4).** There are no credentials, so `ChatOpenAI`, `OpenAIEmbeddings`, the Ragas triad scorer and the Langfuse callback have never run against a live service. These code paths carry `VERIFY:` markers in `src/main.py`, `src/eval/triad.py` and `src/utils/observability.py`. The graph, guardrails and API are tested with labeled test doubles (`ScriptedLLM`, `FakeEmbedder`). With no provider configured, the running app returns 503 on `/ingest` and `/chat`.
- **Ragas import shim.** Ragas 0.4.3 imports `langchain_community.chat_models.vertexai` when it loads. `langchain-community` 0.4.2, the release that works with `langchain-core` 1.x, no longer ships that module. `src/eval/triad.py` registers an empty placeholder module before importing Ragas. Metric imports are tested; scoring is not (see above).
- **Stack additions outside the Gate A lock (flagged at Task 4):** uvicorn 0.53.0 (ASGI server for FastAPI), python-multipart 0.0.32 (FastAPI file uploads), and langchain-openai 1.6.6 (already a transitive dependency of Ragas; now the optional provider). The provider choice is provisional because none was locked.
- **Rename detection is by page-hash overlap.** A renamed file that shares no unchanged page with its previous version is treated as a new document, so its old version stays until it is deleted explicitly.
- **Embedding dimension is fixed at 384** in `schema.sql`; changing providers may require a migration.
- **Resolved during Task 4:** connections now open with `autocommit=True`. Before this fix, writes from Tasks 1–3 were savepoints that were rolled back when the connection closed. Tests had missed it because they read back on the same connection. A regression test now reads on a fresh connection.
